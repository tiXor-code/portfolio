Privacy Policy

Retro Many Money · Last updated 26 April 2026

1. Scope

This policy describes how the "Retro Games Clipper" developer integration handles data when used by its single authorized TikTok account: @retromanymoney. The integration is operated solely by the channel owner; no end-user data from third parties is processed.

2. Data accessed via TikTok APIs

When the channel owner authorizes the integration on the TikTok account, the following scopes and data are accessed:

ScopeDataPurpose
user.info.basicopen_id, display name, avatar URLIdentify which authorized account a request belongs to
video.uploadVideo files uploaded by the channel ownerPlace pre-edited clips into the TikTok app drafts inbox
video.publishVideo files + caption + privacy settingDirect-publish pre-edited clips with channel-owner-supplied caption

3. Storage

OAuth tokens (access token, refresh token, open_id) are stored locally on the channel owner's machine in an environment variables file. They are not transmitted to any server other than TikTok's official API endpoints. Video files are uploaded directly from the channel owner's machine to TikTok and are not retained anywhere else by the integration.

4. Sharing

No data accessed via TikTok APIs is shared with any third party. The integration does not analytics, log, or transmit any personal data to external services.

5. Retention

OAuth tokens are kept until the channel owner manually revokes the integration's access (via TikTok Settings → Manage app permissions) or rotates credentials. There is no remote database; deleting the local environment file removes all stored data.

6. Your rights

Because the integration is operated for the single authorized account holder, that account holder has direct control: revoke at any time via TikTok's app permissions screen, or delete the local credentials.

7. Contact

Questions or revocation requests: retromanymoney@gmail.com

8. Reference

This integration uses TikTok's APIs in accordance with the TikTok API Terms of Service and the TikTok Partner Privacy Policy.
