# Portfolio refresh — design spec

- **Date:** 2026-05-29
- **Branch:** `refresh/2026-05-29-content` off `prod` (tip `90e3a64`)
- **Status:** Draft, awaiting user review
- **Audience for the refresh:** AI-engineering hiring managers and recruiters evaluating Teodor

## Overview

teodorlutoiu.com is already AI-engineering positioned after the May 21, 2026 redesign (commit `90e3a64`). The 7-section page reads cleanly for the AI-eng recruiter audience, with a live ICP agent demo as its centerpiece. This spec covers a **content + small-structure refresh** of that page — no structural redesign. The work that has shipped since May 21 (cv-tailor, GEPA Prompt Lab, the personal wiki substrate, the founding of Ministeru' Creativ) is missing from the site; this refresh closes that gap, fixes data staleness, surfaces ATS keywords, and creates the public GitHub repos the Projects cards will link to.

## Non-functional plan

### Performance budget

- Net JS bundle growth ≤ 5 KB gzipped
- Lighthouse desktop performance ≥ baseline (measure on the May 21 deploy before merging)
- Lighthouse mobile performance ≥ baseline − 2 pts
- LCP ≤ baseline; TBT ≤ baseline
- No new runtime dependencies

### Accessibility

- New GitHub icon in Nav: `aria-label="GitHub"`
- `Download CV (PDF) ↗` text link: visible text already accessible
- ATS strip uses semantic `<dl>` / `<dt>` / `<dd>`
- `prefers-reduced-motion` already respected by the existing build; this refresh adds no new animations
- Color contrast preserved (uses existing `text-ink-dim` / `bg-panel` pairing — WCAG AA)

### Deploy + the rsync gotcha

`deployHost.yml` runs `rsync --delete dist/ ... public_html/` at the document root, which wipes every sibling subdir on each prod deploy.

- Preview testing for this refresh uses a fresh subpath (`/wip5/` or next available)
- After merging refresh to `prod`, all pre-existing preview subdirs (`/wip2/`, `/wip3/`, `/wip4/`) will be wiped again — expected, not new damage
- `public/cv/*` and the new SEO static files at `public/robots.txt` and `public/sitemap.xml` ride through the existing `dist/` → `public_html/` rsync without workflow changes
